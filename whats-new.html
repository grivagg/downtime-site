Downtime - What's new

Version 1.2.0

9 October 2026

  • New game added (Soundings): find all mines in the Sweep mode, and all submarines in the Hunt mode.
  • Full controller support: the library, menus, pause screen and all games.
  • A "What's new" link in Settings, and this note after each update.
  • Interface and stability improvements, and bug fixes.

Version 1.1.2

22 August 2026

  • New game added (Orbits). You need to move the planets to form lines and clear them.
  • Updated graphics in the library, game cards and help screens throughout, and all game assets for Carry On.
  • Minor interface and bug fixes.
  • Updated for Android 16.

Version 1.1.1

4 August 2026

Maintenance update. No changes to gameplay.

Version 1.1.0

31 July 2026

  • Rebuilt on-screen controls: correctly sized on phones, tablets and foldables, and consistent across both games.
  • Tidier portrait layout — outlined board, centred NEXT card, more room in gesture mode.
  • Physical game controllers now work in both games.
  • Clearer How to play illustrations.
  • Better support for large system font sizes.

Version 1.0.12

21 July 2026

  • Fixed the Tight Fit board alignment so the full playfield sits with even margins on all phone sizes.
  • Both games now default to on-screen D-pad controls (switchable in settings).

Version 1.0.11

19 July 2026

  • Landscape support in all games and all screens.
  • Minor UI fixes.

Version 1.0.10

16 July 2026

  • Carry On level select, redesigned — every level now previews its puzzle as a mini board, shows your best move count vs the goal, and marks the ones you've solved in the fewest moves.
  • Tight Fit on-screen controls rebuilt — better layout, timing and haptics, plus counter-clockwise rotate.
  • Cleaner in-game pause menu.
  • Stability improvements.

Version 1.0.9

14 July 2026

Objectives & medals — every game now has objectives to chase, and a medal on its card that shows how far you've come. Bronze, silver, gold.

Tight Fit difficulty rebalanced: the old wall at level 10 is gone. Speed now climbs smoothly all the way to level 16, so good runs go deeper.

You can now open "How to play" from the pause menu.

Version 1.0.8

12 July 2026

  • Tight Fit: line-clear and level-up sounds now play.
  • Tight Fit: holding drop no longer slams the next piece.
  • Carry On: Undo is greyed out when there's nothing to undo.
  • Fixed a freeze that could leave the game stuck with no way to resume.
  • Pause and Restart now behave correctly when a dialog is open.
  • More reliable saving — progress isn't lost if you quit right after a move.
  • Smoother controls and animations, plus bug fixes and stability improvements.

Version 1.0.7

9 July 2026

  • Smoother navigation — screens now animate between library, games, and settings.
  • Library cards show when you last played each game.
  • Added a "more games coming soon" teaser card.
  • Fixed a bug where the back button could occasionally double-navigate on some devices.
  • Bug fixes and stability improvements.
